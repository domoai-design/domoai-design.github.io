SelectionGroup 选择组（分段 / 卡片）

在 Figma 中查看

一组选项，四种形态对应 Figma `type`：segmentedOption 分段胶囊（Monthly / Yearly）、selectableCard 平分宽度的卡片（Agent 面板的 Ratio / Resolution / Audio）、radio 单选、checkbox 多选。

示例

分段：尺寸

type="segmentedOption"（默认）。sm 24px / md 28px（默认）/ lg 32px（Body/16）；选中项白底黑字 Medium，悬停 surface/secondary 底。

1<SelectionGroup aria-label="Billing" size="sm" value={billing} onChange={setBilling}2  options={[{ id: "monthly", label: "Monthly" }, { id: "yearly", label: "Yearly" }]} />3<SelectionGroup aria-label="Billing" size="md" value={billing} onChange={setBilling}4  options={[{ id: "monthly", label: "Monthly" }, { id: "yearly", label: "Yearly" }]} />5<SelectionGroup aria-label="Billing" size="lg" value={billing} onChange={setBilling}6  options={[{ id: "monthly", label: "Monthly" }, { id: "yearly", label: "Yearly" }]} />

分段：图标与禁用

option.icon 为文字左侧 14px 图标（Figma showIcon），颜色跟随文字；option.isDisabled 禁用单项（50%），isDisabled 禁用整组。

1<SelectionGroup aria-label="Mode" defaultValue="fast" options={[2  { id: "fast", label: "Fast", icon: <CubeLineIcon /> },3  { id: "relax", label: "Relax", icon: <ImageLineIcon /> },4  { id: "turbo", label: "Turbo", icon: <LockFillIcon />, isDisabled: true },5]} />

分段：套餐切换 / plain

Pricing 套餐对比用 lg；移动端吸底栏用 variant="plain"（无底色、选项平分宽度、固定 36px）。

1<SelectionGroup aria-label="Plan" size="lg" value={plan} onChange={setPlan} options={…} />2<SelectionGroup aria-label="Plan" variant="plain" value={plan} onChange={setPlan} options={…} />

卡片：图标与锁定

type="selectableCard"：撑满父容器、选项平分宽度。带 icon 时 72px 高（24px 图标在上），纯文字 32px 高；labelIcon 为文字左侧 12px 小图标（如 LockFill 表示需升级）。

1<SelectionGroup type="selectableCard" aria-label="Model" defaultValue="a" options={[2  { id: "a", label: "Video", icon: <CubeLineIcon /> },3  { id: "b", label: "Image", icon: <ImageLineIcon /> },4  { id: "c", label: "Pro", icon: <CubeLineIcon />, labelIcon: <LockFillIcon /> },5  { id: "d", label: "Team", icon: <CubeLineIcon />, isDisabled: true },6]} />

单选 / 多选

type="radio" / type="checkbox"：横向排列、间距 24px；checkbox 的 value 为数组。

使用规范

推荐
✓2–5 个互斥选项、切换后立即生效时用 segmentedOption（宽度随内容）。
✓选项需要撑满面板宽度、或带 24px 图标（比例、分辨率、开关项）时用 selectableCard。
✓需要读清楚每个选项的文字、表单里的单选 / 多选用 radio / checkbox。
✓必须传 `aria-label`，或用 `aria-labelledby` 关联可见标题（如面板里的「Ratio」）。
✓移动端底部平分宽度的套餐切换用 `variant="plain"`。
避免
✕只有开 / 关两种状态时用 Switch。
✕选项超过 5 个或文字很长时用 Dropdown。
✕不要用它做页面导航，导航用 Tabs。
