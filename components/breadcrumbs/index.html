Breadcrumbs 面包屑

在 Figma 中查看

面包屑导航：显示当前页面在层级中的位置，前面的层级可点击返回。

用法

1import { Breadcrumbs } from "@domoai/ui";

示例

基础

链接为 Body/14-400、60% 白，hover 变白并加粗到 500；最后一项是当前页（白色、不可点击），指向它的箭头也为白色。

  1. Home
  2. Projects
  3. Summer campaign
  4. Untitled video
1<Breadcrumbs>2  <BreadcrumbsItem href="/">Home</BreadcrumbsItem>3  <BreadcrumbsItem href="/projects">Projects</BreadcrumbsItem>4  <BreadcrumbsItem href="/projects/42">Summer campaign</BreadcrumbsItem>5  <BreadcrumbsItem>Untitled video</BreadcrumbsItem>6</Breadcrumbs>

两级

  1. Assets
  2. Images
1<Breadcrumbs>2  <BreadcrumbsItem href="/assets">Assets</BreadcrumbsItem>3  <BreadcrumbsItem>Images</BreadcrumbsItem>4</Breadcrumbs>

不跳转，只回调

不传 href 时用 Breadcrumbs 的 onAction 处理点击（如在同一页面内切换文件夹）。

  1. My files
  2. 2025
  3. November
1<Breadcrumbs onAction={(key) => openFolder(key)}>2  <BreadcrumbsItem id="root">My files</BreadcrumbsItem>3  <BreadcrumbsItem id="2025">2025</BreadcrumbsItem>4  <BreadcrumbsItem id="nov">November</BreadcrumbsItem>5</Breadcrumbs>

使用规范

推荐
✓层级 ≥ 2 的页面（如 项目 → 文件夹 → 文件）在标题上方放面包屑。
✓最后一项是当前页，不传 href；它会自动设为 aria-current="page"，显示为白色、不可点击。
✓站内跳转配合 RouterProvider 走 Next.js 客户端路由（同 Link）。
避免
✕不要手写「文字 + 箭头图标」拼面包屑。
✕层级只有一层时不要显示面包屑。
