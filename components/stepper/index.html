Stepper 数量加减

在 Figma 中查看

用减号 / 加号调整一个整数（如团队席位数）。

用法

1import { Stepper } from "@domoai/ui";

示例

团队席位

最少 3 席；到边界时按钮变为 50% 透明度并禁用。

3 Seats
1<Stepper aria-label="Seats" value={seats} min={3} max={50} onChange={setSeats} formatValue={(v) => `${v} Seats`} />

使用规范

推荐
✓数值范围小、通常只加减几步时使用。
✓用 `formatValue` 带上单位（3 Seats）。
避免
✕需要直接输入大数字时用 NumberField。

API 参考

Stepper

属性类型默认值描述Figma 属性
valuenumber—当前值（受控）—
onChange(value: number) => void—变化回调—
min / max / stepnumber0 / ∞ / 1范围与步长；到边界时对应按钮禁用（50% 透明度）—
formatValue(value: number) => ReactNode—中间显示的文字—
aria-labelstring—无障碍名称（必填）—
