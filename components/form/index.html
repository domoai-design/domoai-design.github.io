Form 表单

在 Figma 中查看

表单项 FormField：标签 + 控件 + 说明 / 错误的布局，控件复用 Input / TextArea / RadioGroup / SelectionGroup / CheckboxGroup（对应 Figma `type`）；vertical 标签在上、horizontal 标签在左。标签自动关联控件（aria-labelledby / htmlFor），必填、出错状态自动传给控件。外层用 Form（原生 form + React Aria 校验）。

示例

控件 × 方向

Figma `type` 对应 children 里的控件（Input / TextArea / RadioGroup）。vertical 标签在上、间距 8px；horizontal 标签在左、间距 16px，标签与 Input / TextArea 的首行文字对齐（下移 12px），与单选组同一行。

1<FormField label="Label">2  <Input placeholder="Enter your content" />3</FormField>4<FormField label="Label" orientation="horizontal">5  <TextArea isFilled height={80} isResizable placeholder="Describe your video" />6</FormField>7<FormField label="Label" orientation="horizontal">8  <RadioGroup defaultValue="standard">…</RadioGroup>9</FormField>

必填 / 提示 / 冒号

isRequired（showRequired）在标签后显示红色「*」并让控件必填；tip（showTip）显示 16px 帮助图标，悬停或 Tab 聚焦显示 Tooltip；showColon 在标签后加冒号。

说明与错误

description 显示在控件下方（Body/12-400，tertiary）；isInvalid 时控件变红描边，说明被 errorMessage 替换（Figma 未设计错误态，沿用 Input 的错误样式）。输入少于 5 个字符查看效果。

*
Username must be at least 5 characters.
1<FormField2  label="Username" isRequired3  description="At least 5 characters: a–z, 0–9 or _."4  isInvalid={invalid}5  errorMessage="Username must be at least 5 characters."6>7  <Input value={value} onChange={setValue} placeholder="Enter a username" />8</FormField>

横排对齐

多个横排表单项传同一个 labelWidth，控件左侧对齐；其他控件（SelectionGroup 等）同样放进 children。

*
1<FormField label="Name" orientation="horizontal" labelWidth={72}>2  <Input placeholder="Enter your name" />3</FormField>4<FormField label="Resolution" orientation="horizontal" labelWidth={72}>5  <SelectionGroup type="radio" defaultValue="720p" options={[…]} />6</FormField>

使用规范

推荐
✓带可见标签的输入框、多行输入、单选 / 多选组都放进 FormField，标签写在 `label`，不要再给控件传 aria-label。
✓说明文字和错误提示写在 FormField 的 `description` / `errorMessage`，不要再用 Input 的 helpText / errorMessage（避免两套说明）。
✓标签较短、页面较宽时可用 `orientation="horizontal"`；多个横排表单项传同一个 `labelWidth` 让控件左对齐。
✓必填项传 `isRequired`：显示红色「*」，控件得到原生 required / aria-required，外层 Form 提交时自动校验。
✓需要额外解释、又不想常驻显示的说明放 `tip`（帮助图标 + Tooltip）。
避免
✕TextArea 放进 FormField 时不要再传 `title`，标签由 FormField 提供。
✕不要用 FormField 包按钮、开关等自带文字的控件；开关用 Switch 自身的文字。
✕不要用 className 改标签颜色、字号或间距。
