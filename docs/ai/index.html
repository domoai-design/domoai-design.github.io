AI 使用规范

让 Claude Code / Cursor 等 AI 写页面时遵守设计系统。规则写在仓库根目录的 AGENTS.md，AI 打开项目时会自动读取。

AI 写页面前会先读

文件内容
packages/ui/COMPONENTS.md有哪些组件、属性怎么传、什么时候用
packages/tokens/TOKENS.md颜色、文字、圆角、间距、断点对应的类名
packages/icons/ICONS.md可用图标

硬性规则

要做不要做
组件从 @domoai/ui 引入直接引入 HeroUI
颜色用语义类（bg-surface、text-foreground-secondary）写死颜色、用 Tailwind 默认色板
文字用 typo-*（typo-body-14-500）拆开写字号和字重
响应式只用 md:（tablet）和 xl:（desktop）sm:、lg:、2xl:
设计系统里没有的东西，先组合现有组件，再考虑新增组件在页面里手写一个新样式

其他项目里的 AI 怎么读

网站上有一组专门给 AI 读的说明文件（不需要登录，只含组件用法和规则，不含源代码）。在 Claude、Cursor 等工具里把下面这段话发给 AI，它就会先读说明再写页面。

地址内容
/llms.txt入口：简介、规则摘要和下面几份文件的链接
/llms-full.txt规则 + 组件 + Token + 图标，一个文件读完（推荐）
/ai/components.md全部组件、属性、用法、示例代码
/ai/tokens.md颜色、文字、圆角、间距等类名，以及与 Figma 变量的对照
/ai/icons.md全部图标和中英文关键词
1写页面前，先阅读 DomoAI Design System 的说明：https://<组件库网站域名>/llms-full.txt2只使用其中的组件（@domoai/ui）、Token 类名和图标（@domoai/icons），遵守「规则」一节；3设计系统里没有的东西，先用现有组件组合，不要自己写颜色、字号和圆角。

自动检查

工程师运行 pnpm lint 时，会自动检查页面代码有没有违反上面的规则，并指出具体位置。
