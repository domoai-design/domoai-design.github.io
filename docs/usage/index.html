安装与使用

在 DomoAI 的 Next.js 项目中接入设计系统（给工程师看）。

1. 引入样式

在 app/globals.css 中只需要一行：

1@import "@domoai/ui/styles.css";

2. 加载字体

1import { Host_Grotesk, Instrument_Serif, Roboto_Mono } from "next/font/google";23const sans = Host_Grotesk({ subsets: ["latin"], variable: "--font-sans-loaded" });4const display = Instrument_Serif({ subsets: ["latin"], weight: "400", variable: "--font-display-loaded" });5const mono = Roboto_Mono({ subsets: ["latin"], variable: "--font-mono-loaded" });67// <html className={`dark ${sans.variable} ${display.variable} ${mono.variable}`} data-theme="dark">

3. Next.js 配置

1// next.config.ts2export default { transpilePackages: ["@domoai/ui", "@domoai/icons", "@domoai/tokens"] };

4. 使用组件

1import { Button } from "@domoai/ui";2import { CubeLineIcon } from "@domoai/icons";34<Button variant="primary" startIcon={<CubeLineIcon />}>Generate</Button>

组件只从 @domoai/ui 引入，不要直接引入 HeroUI。
