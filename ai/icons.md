# DomoAI Icons

单色图标：`import { CubeLineIcon } from "@domoai/icons"`，颜色跟随 `text-*`，尺寸用 `size` 属性（默认 24）。
品牌 / 模型 Logo（多色）：`import { ... } from "@domoai/icons/brand"`。DomoAI 自身的 Logo：`<DomoAILogo variant="full" | "icon" />`。

命名：`XxxLine` 线性、`XxxFill` 面性（同一对共用基名）。选图标时按下表的关键词匹配用途，不要自己画或引入第三方图标。
